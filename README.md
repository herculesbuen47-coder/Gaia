# Ikarus — Bot Discord Visual Novel\n\nExperiência narrativa em Discord com Gaia e o narrador Ikarus.\n\n## Recursos\n\n- 5 capítulos, 7 blocos por capítulo\n- Narrativa imersiva, escolhas e múltiplos finais\n- Atributos invisíveis: razão, emoção, vazio, investigação e ação\n- Comando `/status` para ver tendências e registro recente\n- Comando `/continuar` para prosseguir na história\n\n## Instalação\n\n1. Clone ou copie o projeto.\n2. Instale dependências:\n\n```bash\nnpm install\n```\n\n3. Crie um arquivo `.env` a partir do `.env.example` e adicione o token do bot e o ID do cliente.\n\n4. Execute o bot:\n\n```bash\nnpm start\n```\n\n## Uso\n\n- Use `/continuar` para iniciar ou continuar a história.\n- Use `/status` para acompanhar as tendências de atributos e o histórico recente.\n\n## Estrutura\n\n- `src/index.js`: lógica do bot e fluxo de jogo\n- `src/story.js`: capítulos, blocos, escolhas e finais\n- `src/stateManager.js`: persistência do progresso do jogador\n- `data/progress.json`: armazenamento local do estado do jogador\n
